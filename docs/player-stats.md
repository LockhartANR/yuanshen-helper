# 玩家数据（PB 表、前端成绩与赛博大表）

给站内任意用户重算 PB、前端成绩和赛博大表，入口有四处：

- popup 搜索结果行右侧的图表按钮：看**别人**；
- popup 头部「我的成绩」：看**自己**，不用先搜自己；
- popup 中间「本地 CSV 分析」：打开 `player.html?source=csv`，不需要玩家 ID，不请求网站数据；
- openms.top 玩家页的「赛博大表」：点击后在站内展开 `player.html?id=<用户ID>&embed=analysis`。

前两者都打开扩展页 `player.html?id=<用户ID>`。自己的 ID 优先取站点登录态（打开 openms.top 时由内容脚本记录），没有就弹窗让用户填一次，也可以在设置页「玩家数据」里改。

启动参数在 `src/features/player-stats/launch.ts` 统一解析：`source=csv` 表示独立 CSV，`view=analysis` 直达大表，`embed=analysis` 表示嵌入布局。外部 iframe 只允许 `embed=analysis`；未知取值或 `source=csv` 与 `embed` 同时出现都会显示参数错误。

赛博大表的统计方式来自大表 **ArbiterStatsAuto**，默认参数为大表 **57.8**。原作者主页：[openms.top/#/player/48](https://openms.top/#/player/48)。

## 数据来源

| 接口 | 用途 | 限流 |
| --- | --- | --- |
| `GET /api/userprofile/videolist?user_id=N` | 全部录像的 `id / upload_time / state / ongoing_tournament` | 1/s |
| `GET /api/video/staticdetailbatch?ids=...` | 解析字段，单批 100 个 ID | 5/s |

明细只抓 `state === 'c'` 且非比赛录像；打开「含未过审」开关时才补抓 `a/b/d/e`，已抓过的走缓存。每批之间串行 260 ms，429 按 2/4/8 秒退避。

### 本地 CSV

支持 Arbiter / Anthropic stats CSV（31 列表头），单文件上限 20 MB。首次选择后记住关联文件，之后点击「刷新」读取最新内容。清单与上次成功读取摘要保存在本机，解析后的录像只在当前页面内存中；CSV 与网站数据分开，不写网站玩家缓存。

- **打开与刷新**：重新打开只恢复清单和标为「上次读取」的摘要，不自动读文件或弹授权框。点击刷新读取全部来源，整批成功后一次替换统计；任一文件失败或取消，保留原快照和成功时间。只有全部来源已加载才展示统计，添加局部文件不能冒充完整快照。
- **文件管理**：支持添加、重新关联、移除和移除全部。原位置同名覆盖、条目减少或成绩改写均以当前完整内容为准，不向旧数据追加；重新关联保留来源位置。移除只删除关联及本页对应数据，不删除磁盘文件。
- **身份与重复**：同一个文件不会重复关联，其他目录下的同名文件可并存，以「来源 1 / 2」区分。单个文件内部和不同文件之间的重复录像仍按原样计入，不做内容去重。
- **权限与降级**：需要权限时，点击文件行的「授权读取」后再次刷新；文件失效时使用「重新关联」。不支持文件句柄 API 的浏览器保留临时导入，并提示重新打开后需要再次选择。更换浏览器配置后需重新选择文件。
- **错误与空文件**：空白文件、表头或引号结构错误、全部数据行无效均为文件级失败；正确表头加 0 行数据是合法 0 局。部分无效行跳过，保留有效行并提示文件名和物理行号，问题详情最多展示前 50 项。局数变化只代表有效局数差值，不代表精确识别出的新增录像。
- **字段与筛选**：日期按本地时区解释；`BEG/INT/EXP` 对应三级，`Flag/NF` 忽略大小写，原始点击字段保留，3BVS 按 `BBBV / Time` 重算。BBBV 为安全整数，初级 1–54、中级 1–216、高级 1–381。支持 NF、时段与 3BV 下限，不显示软件筛选；今日成绩统计当天全部有效局。
- **入口与切换**：独立 `player.html?source=csv` 无需玩家 ID，默认进大表，移除全部后仍留在 CSV 空态。普通玩家页默认网站数据，切回网站会取消未提交操作并保留关联和本页旧快照，移除全部后返回网站数据。站内嵌入大表不提供 CSV 操作。
- **多页面与取消**：同一浏览器配置共用清单，重获焦点或再次操作时发现其他页面的修改；重新关联和移除使对应旧成绩失效，刷新保留已应用筛选、清理旧流水定位。切源、移除全部、销毁或取消后，晚到结果不能恢复数据、写回关联或自动切源。
- **联网与锚点**：独立 CSV 不调用网站玩家接口，即使保存了网站锚点模式也不自动刷新锚点。锚点仍按用户设置计算，显式点击「读取并使用网站锚点」才联网读取。

实现上以 `sourceId` 标识来源、`isSameEntry()` 判断文件身份；内存与 IndexedDB 共用清单更新规则。添加和重新关联采用事务内清单版本校验，重新关联还会提升来源版本，使其他页面的旧快照失效。所有选择入口共用带操作标记的上下文；完整快照按来源及文件行顺序分配唯一负 ID，确保反复刷新不改变并列取舍。

### 站内赛博大表

在 `https://openms.top/#/player/<ID>` 玩家页显示「赛博大表」入口，默认开启，可在设置页关闭。站点会把 `#/player/<ID>` 重定向到 `#/player/<ID>/top`，入口在重定向前后都保持挂载，不会闪烁或重复创建。

- 初次进入只挂载入口，不创建 iframe，也不请求录像列表或明细；点击后才在页面内展开完整大表（扩展 iframe，`embed=analysis`），自动带入当前玩家 ID。
- 入口优先挂在玩家信息附近；找不到目标容器时退回右下角的小入口。同一时刻只显示一处入口。
- 大表宽度跟随容器，高度有界并在 iframe 内部滚动；加载进度、失败原因、缓存时间和缺失明细提示都在大表内部，刷新 / 取消沿用网站玩家加载语义。
- 收起会销毁 iframe 及该视图的请求；「独立打开」打开同一玩家的 `player.html?id=<ID>&view=analysis`。嵌入失败或 10 秒内没有收到就绪消息时提示改用独立打开，不无限重试。
- 切换玩家、浏览器前进 / 后退、离开玩家页、关闭设置开关都会销毁旧入口与 iframe，旧实例的晚到消息不会回写；重新开启开关只恢复入口，不自动展开。
- 嵌入视图不显示 CSV 导入、成绩概况导航和站点主页导航。站点 DOM 改版或 CSP 拦截嵌入时，入口定位或 iframe 可能失效，独立打开始终可用。

扩展只向 `https://openms.top/*` 开放 `player.html`，不额外开放脚本、字体或其他页面。嵌入页与独立玩家页共用扩展缓存和参数，仅向父页面发送就绪状态；接收端校验消息来源、窗口、玩家 ID 和当前实例。

## 口径

| 维度 | 规则 |
| --- | --- |
| 等级 | `b` / `i` / `e`，自定义难度不计 |
| 模式 | `"00"` 标准，无猜等不计 |
| 审核状态 | 默认只要 `c` 已过审；开关可纳入 `a/b/d/e`，此时结果仅自用，和站点不一致 |
| 比赛录像 | `ongoing_tournament` 一律不计 |
| NF | 网站 PB / Top5 按 `right_ce === 0`，大表按 `right === 0`；CSV 统一按 `style=NF`。NF 录像同时计入未限制 NF 的榜 |
| 无效成绩 | `bv` 为空或 `timems <= 0` 不计（站点 PB 会把 0ms 当纪录，我们不跟） |

## 指标

```
seconds = timems / 1000
3BVS    = bv / seconds
STNB    = 系数[等级] × bv / seconds^1.7    # 初 36，中 162，高 435
```

- **PB**：按 `(等级, 3BV)` 取用时最短的一条，并列先比上传时间，再比网站 ID 或 CSV 导入顺序（先导入优先）；没有 3BV 下限。
- **前端成绩**：每个 `等级 × 指标` 取前 5，NF 与未限制 NF 各取一份，指标为用时（升序）、3BVS（降序）、STNB（降序），并列先用时短；3BV 下限默认初 10 / 中 30 / 高 100，可在参数里改。
- **配色**：默认用原表 `Set!AE2:AE30` 的 29 色板——3BVS 按阈值 9 → 0.01 取色，STNB 用同一阈值 ×25；用时按 `12 − 2x`（初）/ `30 − 4x`（中）/ `90 − 10x`（高）取色。29 档阈值可在参数里改。超出最高档或低于最低档不填色，文字按背景感知亮度取黑或白。阈值与颜色见 [color-scheme.txt](color-scheme.txt)。
- **软件图标**：PB 格子和前端成绩的每个成绩前面显示录像所用软件的小图标（a=Arbiter、e=Metasweeper、m=Clone、r=Vienna）。
- **日期**：PB 表多一个「日期」页签，切过去后格子显示该条 PB 录像的结束日期，统一为 `YY/M/D`（如 `25/5/24`，本地时区）；结束时间缺失时显示 `—`。日期格按该难度最早红 / 50% 白 / 最新蓝上色。
- **GC**：按 3BV 分段，使用未套用 3BV 下限的录像；分段 `rateSum` 包含该段所有 3BV，没有成绩的 3BV 其 PB 3BVS 按 0 计；`ASB` 为除初级 2–9 外每个有成绩 3BV 的 PB 3BVS 之和；分段战力为 `Σ(PB 3BVS × rate) / Σ(rate)`；分段典型 3BV 为 `Σ(bv × rate) / Σ(rate)`；中级 3BV > 134、高级 > 278 时 rate 按 0 计；分段典型时为分段典型 3BV ÷ 分段战力；总典型时为各分段典型时之和，总战力为 `Σ(PB 3BVS × rate) / 100`。

## 赛博大表

`player.html` 顶部分成「成绩概况 / 赛博大表」两页。赛博大表现在接了八块：

页头显示来源总量与更新时间；「成绩概况」筛选旁的「PB 筛选计入」只用于 PB 表。大表的「统计样本」应用自身的软件 / NF / 日期筛选与当前 3BV 下限，月年局数、今日成绩和全时段定阶仍使用各自口径。数据源尚未读取时不显示空统计。

大表筛选与页签支持吸顶；编辑参数或日期时暂时取消吸顶并定位到编辑区，结束编辑后恢复入口焦点。今日成绩按当前数据源的基础有效记录独立统计，不受公共筛选与统计 3BV 下限影响；三难度都没有成绩时显示「今日暂无成绩」。周明细标明所属周，窄屏按单列排列，复制不影响展开状态。

| 页签 | 内容 |
| --- | --- |
| 概览 | 定阶总览（三级与综合的软实力 / NF软实力 / LSF / 定阶 / NF定阶）、近 30 天新 PB、本周 T37、活跃天数、今日成绩（不受 3BV 下限限制；初中高 FL/NF、Best/Avg Time、3BVS、STNB、Avg 3BV）、三难度摘要、GC 指标（ASB / 战力 / 典型时，含按 3BV 分段明细）、活跃日历（12 周热图 + 统计卡）、最近 PB |
| 梁山分 | 定阶总览表、时段统计（卡上切时段，支持快捷项与自定义日期：时段涨分 / 涨分次数 / 单局最大涨分 / 单日最大涨分 / 时段末 LSF，两个最大值可点击定位流水）、历史阶梯图、变动流水（默认时间倒序，可展开原因，图点可定位） |
| 榜单 | 用时 / 3BVS / STNB 三类 Top 50，可按难度切，也可切「三难度」纵向各看前 10 |
| 趋势 | 周 T37 / B37 / S37 / ppp（含 10/30/99 秒占位补齐，点周行展开双列瀑布槽位明细；每行可复制，固定六行含三级分解）、月均明细（月份、活跃天数、局数、日均、平均、op/is、点击效率、转化、路径、1/破率、头部表现、新 PB；点月份展开用时分档 / 3BVS 分档；每行可复制）、年汇总（三级三卡纵向排列，每行可复制） |
| 月年 | 按月 / 按年取每期前 8 / 14 条（默认，可调），可切指标与难度 |
| 分布 | 3BV 分档、Sub 率（默认 14 档，可调）、3BV 区间（rAvg，初级含 2–9，实际 / 理论占比） |
| 效率 | cl/s、ce/s、移速、IOE 四项前 5，外加杂项 7 项：最少 / 最多有效点击、最小路径、最少 / 最多岛屿、最少 / 最多开空 |
| 地图 | 时间 × 3BVS 热图（空格按理论 STNB 回填）、效率前沿线、狗预测 |

口径在 PB 表的基础上再加两条：**3BV 下限默认 10 / 30 / 100**（对齐工作簿的各级下限，可在参数里改），**NF 用右键数 = 0**（工作簿口径；PB 表那边仍是站点的 `right_ce = 0`，两者会因为无效右键略有差异）。不本地判重，站点返回的重复上传按原样计入。赛博大表顶部的「只看 NF」对所有页签生效，**只有梁山分页签例外**：该页禁用软件与「只看 NF」，始终同时统计 NF 与非 NF 记录，只用时间范围截取历史部分。

顶部「参数」可调：榜单 Top、月 Top / 年 Top 条数、效率 / 杂项 Top、Sub 档数、软实力三项权重、三级权重、T37 槽位与补位用时、PPP 常数、3BV 下限、29 档色板阈值；默认参数为大表 **57.8**，原作者主页见上。锚点区可手动改 18 项锚点（含 NF锚点），或点「使用大表锚点」/「读取并使用网站锚点」切换；展开「狗预测」可改高级 / 中级目标。参数保存在本机 localStorage，刷新后仍生效，「恢复默认」还原。月均 / 年汇总的复制选项也随这套参数保存，总「恢复默认」会一并清空；卡片内「恢复默认」只清空对应复制选项。

指标：

```
cl   = left + right + double
ce   = left_ce + right_ce + double_ce
path = path / 16（格）
移速 = path / 16 / seconds
corr = ce / cl
thrp = bv / ce
```

- **PB 标记**：按结束时间顺序扫，每个 `(等级, 3BV)` 用时更短即记为一次新 PB，同时记下被打破的旧纪录；首条不算「新 PB」。
- **周**：以周一为起点，取最近 10 周；没有成绩的周不显示。T37 = 初级最快 20 条用时 + 中级最快 12 条 + 高级最快 5 条，不足槽位按 10 / 30 / 99 秒补齐；槽位和补位值可在参数里改。B37 / S37 用同样槽位取 3BVS / STNB（缺位补 0）。T37 越小越好，ΔT37 是相对上一个有成绩的周。点周行展开双列瀑布明细：左列初级，右列中级 + 高级；含三级槽位表、总计 / 平均，以及底部 T.37 / B.37 / S.37 / BPP / IPP / EPP / PPP37。
- **ppp**：`cbrt(∏(S×B/T / 常数 / 槽位))`，三等各一项；常数为 69.690991、5.783604、1。
- **效率 / 杂项**：IOE = `bv / cl`；「最少 / 最多有效点击」显示 `ce` 原值，「最小路径」显示原始 path（1/16 格），「最少 / 最多岛屿」显示 `isl`，「最少 / 最多开空」显示 `op`。
- **年汇总**：按年聚合，三级各一张卡片纵向排列；每卡给出局数、平均用时 / 3BV / 3BVS / STNB、cl/s、ce/s、移速、新 PB。
- **1/破率**：`floor(50 × 当月局数 / 当月进入全时段前 50 的次数)`，前 50 按用时 / 3BVS / STNB 三张榜累计。
- **头部表现**：新 PB × 5 + 前 5 次数 × 15 + 前 6–25 次数 × 7 + 前 26–50 次数 × 2。
- **狗预测**：按年度取当前难度累计局数首次 > 20 的时间点作为基准，向更快的目标按 `1.55 / 2.3 / 3.8` 分段衰减，输出各年预测达标概率。
- **月**：按本地时区归月，覆盖最早录像到最晚录像之间的全部月份，倒序排列（最新在上）；没有成绩的月份保留为空行。月 / 年局数统计全部录像（含低于各级下限的局），平均、Top 和 PB 只取达到各级 3BV 下限的局。

### 周月年数据复制

趋势页的周 T37、月均与年汇总每行末尾都有「复制」，使用当前页面的统计结果与筛选条件，点击时不再重新聚合录像。所有复制文本、复制预览与复制按钮上展示的日期统一使用斜杠（`2026/11/01`、`2026/11`、`2026/10/26–2026/11/01`），月份和日补两位，年汇总只写年份；月份的内部键、日期控件和筛选边界仍是原来的格式。

周 T37 固定六行，第一行为「周成绩 · 周日期」（本地时区的周一至周日，两端都写出），第二行只有局数与 ΔT37，后四项各占一行并带三级分解：

```text
周成绩 · 2026/10/26–2026/11/01
Games 128 | ΔT37 −12.3
T37 820.1 = 200.0 + 300.0 + 320.1
B37 42.1 = 12.1 + 20.0 + 10.0
S37 1532.4 = 500.4 + 600.0 + 432.0
PPP 2.154 = ∛(1.234 × 2.345 × 3.456)
```

- 三级分项与因子固定按**初级、中级、高级**排列，取各级总计（`totals.time / bvs / stnb`）和各级 PP；PPP 是三个因子的乘积开立方，不是相加。
- T37 / B37 / S37 的总值与分项各保留 1 位小数，PPP 的总值与因子各保留 3 位，局数为整数不加千位分隔符。统计、求和与开立方都先用未舍入值，最后才格式化。
- ΔT37 = 当前周 T37 − 当前列表上一条有成绩周的 T37（中间空周直接跳过，不改用上一个自然周）；列表第一条没有前项，输出 `—`。正值带 `+`、负值用 `−`，舍入后为零时输出 `+0.0`，不出现 `−0.0`。
- 四项三级分解统一使用 `=`；总值与分项各自按约定精度显示，允许独立舍入产生尾差，不调整真实分项，也不改变统计值。
- 软件 / NF 限制标记放在第一行末尾（如 `周成绩 · 2026/10/26–2026/11/01 · avf · 仅 NF`），未限制时不写「全部」「普通」，也不给周综合结果贴难度。
- 全局时段只截取自然周的一部分时，统计日期并入第一行括号：`周成绩 · 2026/10/26–2026/11/01（统计日期 2026/10/28–2026/10/30）`，整体仍是六行；该日期取该周与已应用时段的交集。
- 周复制内容固定；槽位数、补位值与 PPP 常数沿用当前参数，修改后六行内的总值与分项同步变化。

月均与年汇总保留各自的「复制设置」与原有内容结构，默认文本：

```text
月成绩 · 2026/10 · exp
Games 1200 | 活跃 20 天 | 日均 60.0
Avg T 65.432 | B 2.345 | S 88.8 | 3BV 150.2
```

年汇总第一行改为 `年成绩 · 2026 · exp`，第二行为 `Games 12345 | 新 PB 28`。难度标签为 `beg / int / exp`；月均「日均」按活跃天数计算。

| 卡片 | 顶部「复制设置」可选指标 |
| --- | --- |
| 月均 | 中位用时、op、is、cl/s、ce/s、Corr、Thrp、路径、移速、1/破率、头部表现、新 PB |
| 年汇总 | cl/s、ce/s、移速；三个难度共用一套选项 |

可选项默认关闭，勾选后按固定分组和顺序追加到文本末尾，预览实时更新。设置只影响复制内容，不改表格列；月均与年汇总独立保存，刷新后仍生效。复制列吸附在表格右侧，窄屏时表格内部横向滚动、页面本身不横向溢出。

没有成绩的周不显示；月均空月份不能复制，有局数但无达标成绩时仍可复制，成绩指标用 `—` 占位。缺少明细字段或破率为 0 时，对应指标输出 `—`，其他真实零值保留。月均 / 年汇总卡片内的「恢复默认」只清空对应复制选项，顶部「参数」里的「恢复默认」还原全部分析参数。

## 定阶 / 软实力 / LSF

概览与梁山分两个位置的定阶、软实力、LSF 都按**全时段（全部录像）**计算，默认使用大表锚点，并且共用同一套计算结果与渲染组件。

- **判定下限**：赛博大表各页签、前端成绩 Top5 和 LSF 都使用各级 3BV 下限，默认 10 / 30 / 100，可在参数里改；rAvg 分布仍保留初级 2–9。
- **大表锚点**：默认取 `Set!AH27:AL35` 的 18 个标准值（锚点 / NF锚点 × 三难度 × 用时 / 3BVS / STNB），可在参数里逐项修改；「恢复默认」回到这组值。
- **网站锚点**：点「读取并使用网站锚点」时从 `GET /api/common/loginauto` 的 `top_anchors` 读取站点当前锚点（每项 20 个样本），缓存 6 小时；点「使用大表锚点」切回默认。
- **用时精度**：保留录像原始毫秒精度（`timems / 1000`），不按厘秒截断；3BVS / STNB 用同一用时计算。
- **单项软实力**：设玩家某项 top5 均值为 `V`、锚点为 `A`，用时 `A/V`，3BVS `V/A`，STNB `(V/A)^(1/1.7)`；两项各自用对应锚点（NF 用 NF锚点）。
- **单级软实力**：用时 / 3BVS / STNB 默认权重为初 `32/48/20`、中 `36/36/28`、高 `32/32/36`，可在参数里改；三项都达到锚点时为 100。
- **综合软实力**：默认初级 × 6 + 中级 × 14 + 高级 × 20，可在参数里改；全部达到锚点为 4000。
- **LSF**：每级先算 `0.97 × 单级软实力 + 0.03 × 单级NF软实力`，再按级别权重相加；三级 LSF 贡献相加等于综合 LSF。
- **定阶**：按等价 et（高级用时锚点 / 归一化综合软实力）映射到「新手 → 外星人」，区间内按软实力线性插值，超过 25 秒继续外推。
- **单级定阶**：把单级软实力按固定 100 尺度换算到 4000 尺度（等价 `titleFor(S × 40, 高级用时锚点)`），NF定阶用 `NF软实力 × 40` 与 NF 高级用时锚点。单级定阶因此不随级别权重变化，也不用该级初 / 中级秒数去套高级称号边界。
- 不足 5 条时按站点规则补齐：用时补 `999.999` 秒，3BVS / STNB 补 0；某个等级完全没有数据时该级按 0 计。某级已有录像但还没有 NF 录像时，NF 项仍按补位值参与，会产生很小的 NF软实力基线。

### 定阶总览表

概览与梁山分页签顶部使用同一张表，行依次为初级、中级、高级、综合（综合是合计行，放在三级下面），列顺序固定为 **级别 / 软实力 / NF软实力 / LSF / 定阶 / NF定阶**：

| 级别 | 软实力 | NF软实力 | LSF | 定阶 | NF定阶 |
| --- | ---: | ---: | ---: | --- | --- |
| 初级 / 中级 / 高级 | 该级 `S` | 该级 `N` | 该级贡献 `W × (0.97S + 0.03N)` | 单级定阶 | 单级NF定阶 |
| 综合 | 综合软实力 | 综合NF软实力 | 综合 LSF（三级贡献相加） | 综合定阶 | 综合NF定阶 |

- 软实力 / NF软实力是单级 100 尺度，LSF 列是乘过级别权重的贡献，两者尺度不同；综合行的两项软实力同样按级别权重加总。
- 精度：软实力、NF软实力保留 1 位小数，LSF 与差值保留 2 位小数，定阶进度保留 1 位小数；计算与比较始终用未格式化的值，零分是有效值。
- 没有 NF LSF 列，也没有「全部 / 普通」这类分组表头；窄窗口与站内 iframe 下表格横向滚动，保留完整五列。

### 命名规则

只有明确限制 NF 的指标才加 NF 前缀。未限制 NF 的指标直接用名称：**软实力、定阶、用时、3BVS、STNB**；限制 NF 的写 **NF软实力、NF定阶、NF用时**。不使用「全部软实力」「普通用时」这类前缀，也不设置「全部 / NF」分组表头。这条规则同样适用于提示、图例、展开明细、无障碍标签与说明文案；内部的 `std` / `nf` 键与接口字段保持不变。「全部软件」「全部时段」等真实筛选项不属于指标前缀。

对应到现有界面：参数表头是「锚点 / NF锚点」，前端成绩两张表是「前端成绩 / NF前端成绩」，定阶总览是「软实力 / NF软实力」「定阶 / NF定阶」；榜单、流水不再写「普通 + NF」「全部录像」这类范围标注，只有真的筛选 NF 时才显示「仅 NF」。

## 梁山分页签（LSF 历史）

「梁山分」页签展示按录像重建的 LSF 变动历史：哪一局改变了分数、改变了多少、来自哪些指标。

- **定阶总览表**：当前完整快照，不随所选时段变化。
- **时段统计**：卡片右上角直接切时段，和顶部筛选条的「时间」是同一个筛选项。五张卡片依次是：**时段涨分**（区间末 LSF − 区间起点 LSF，保留真实负值）、**涨分次数**（区间内正向变化事件数）、**单局最大涨分**、**单日最大涨分**、**时段末 LSF**。选更短的时段时，区间起点是该时段开始前的累计 LSF，所以时段涨分通常小于总 LSF。
  - **单局最大涨分**：区间内单条事件的最大正向差值，并列取最近一条；点击（或键盘激活）定位到该条流水，必要时自动加载到目标行、展开并高亮。
  - **单日最大涨分**：区间内某本地自然日全部事件差值之和的最大正值（同一天的正负变动一起求和），并列取最近一天；点击定位到该日最新一条流水，并高亮当前已显示的该日流水，不会隐式切换成单日筛选。
  - 没有正向涨分 / 正向日增量时对应卡片显示 `—`，不产生跳转。
- **历史阶梯图**：横轴日期、纵轴累计 LSF，用台阶线表现离散录像带来的变化；悬停或键盘聚焦看分数与来源，点击定位到流水。所选时段事件极多时，图上只标出等距抽样的台阶点，台阶线与流水仍是完整记录。
- **变动流水**：默认时间倒序，只列出确实改变了 LSF 的录像；展开可看被改写的 Top5 榜、名次、被替换成绩、均值前后值、各项折算后的 LSF 贡献差值、该级与综合 LSF 前后值、新旧录像链接。该级首条录像会多一行「初始化基线」：该级此前按 0 计，但各榜「变化前」是空榜补位值，补位折算出的金额要显式计入（含单独的 NF补位金额），明细下方给出「合计」，各榜差值与初始化基线相加等于本次涨分。

### 时段选择

全局与梁山分页内共用时段，顺序为：**全部、今天、昨天、本月、上月、今年、去年、近7天、近30天、近90天、近一年、自定义**。

日期按浏览器本地时区计算，起点含开始日零点，终点不含结束日次日零点。「近7 / 30 / 90天」含今天，「近一年」为含今天的365个自然日；本月 / 今年从本月1日 / 今年1月1日至今天，上月 / 去年为完整自然月 / 年。「全部」不设日期边界。

选择「自定义」后填写起止日期，点「应用」生效；允许同一天，日期缺失、倒置或晚于今天时给出错误并保留原范围。编辑期间结果不变，「取消」恢复已应用状态。已应用自定义时，两个入口都有「编辑日期」按钮；再次打开会回填本次会话中上次有效的范围，没有历史值时回填今天至今天。

快捷项在重新应用、刷新数据或跨午夜后重绘时更新边界。选择历史时段会同时限制起点和终点，之后的成绩不进入该时段的统计、图表与流水。定阶总览始终显示当前完整快照。

### 重建口径

- 只统计标准三级难度、模式 `00`、已审核且非进行中的有效录像；各级 3BV 下限沿用参数（默认 10 / 30 / 100）；网站与 CSV 分别计算；用原始毫秒用时。
- 先按时间升序整理完整录像集，再逐条更新每级 6 个榜（用时 / 3BVS / STNB 及其 NF 榜，共 18 个 Top5），最后一份状态与直接调用快照计算完全一致。
- 分析记录、全局筛选和历史重建共用有效日期：优先录像结束时间，无效或非正数（包括 epoch 0）时退回上传时间，两者均不可用时标记为未定日期。同一时间按网站 ID / CSV 导入顺序；Top5 单项值相等时沿用这个先后。一条录像同时改善多项指标只算一次涨分；分数不变时不生成事件。
- 事件和明细贡献使用未舍入数值计算，保留每项非零贡献。微小变动舍入后不足 0.01 时显示为「+<0.01」；贡献逐项显示后的和可能因舍入与总差值相差 ±0.01。
- 时段起点只累计严格早于所选起点的记录，恰好在起点的录像计入区间；终点是所选终点与真实当前时刻取较早者（「全部」不设终点）。完整范围从零基线（含未定日期基线）开始；未定日期记录只作基线，不参与单局 / 单日最大涨分。
- 修改锚点、三项权重、级别权重或 3BV 下限后整份重建，不混用旧流水；补入更早的录像会插入其结束时间位置并重建后续历史。
- 两个时间都无效的录像作为「未定日期基线」先计入并单独提示，不假定它发生在最早日期；晚于当前时间的记录仍留在完整快照里，但不进时段历史与流水，页面会明确提示两者差异。
- 时段只截取时段统计、阶梯图与流水（卡上切换或改顶部「时间」都会同步）；软件与只看 NF 在该页禁用（离开时恢复原有选择），计入局数按梁山分自己的口径显示。
- 切换数据源 / 玩家、刷新 CSV 快照、移除 CSV 来源、销毁嵌入页都会清掉旧历史与展开定位状态，晚到的异步结果不会回写。

> 页面展示的是基于当前可用记录重建的成绩成长史：锚点与参数按当前值统一重算，不能还原当年网站显示的分数或过审时刻。

## 缓存

Details 按 `[userId, id]` 存 IndexedDB，`fetchedAt` 单独记；24 小时内再次打开不请求，刷新只补新 ID。`state` 以每次的 `videolist` 为准，所以审核状态变化不需要重抓明细。

明细字段版本记在 `playerMeta.version`；v3 起要求核心 `timems / bv` 有效，`path / op / isl` 缺失时按部分可用缓存（路径、IOE、杂项等跳过该局）；点「刷新」或缓存过期时会重新拉取部分明细，站点补全字段后可恢复。旧缓存会重拉一次（约 20 秒 / 6000 局）。

## 对拍

```bash
npm run verify:player -- 16
OPENMS_BASE=http://127.0.0.1:8000 npm run verify:player -- 16
```

脚本会拉一遍录像、本地重算，再和 `/api/speedranking/{pb,top}/player/{id}` 逐条比。已知站点侧差异会作为提示输出、不算失败：

- 站点 PB 里有 0ms 的脏数据；
- 站点 PB 缓存偶尔没跟上新过审的录像（我们算出的更快）。
