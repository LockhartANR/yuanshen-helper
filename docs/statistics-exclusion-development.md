- 使用说明：[玩家数据 · 录像统计排除](player-stats.md#录像统计排除)。本文只保留身份、存储和异步一致性约定。

## 1. 数据流与职责

```text
网站原始缓存 / CSV 成功读取快照
  → 按来源作用域加载规则并匹配原始条目
  → 保留管理列表，生成排除后的统计候选数据
  → PB / Top5 / 今日 / 周月年 / GC / 分布 / 效率 / LSF / 定阶 / 复制
```

排除是全部统计的上游条件。各消费者继续使用原有审核、模式、软件、NF、3BV 和日期口径；不能绕过候选数据重新计入已排除录像。网站缓存和 CSV 成功读取摘要不被裁剪。

| 模块 | 职责 |
| --- | --- |
| `statistics-exclusion.ts` | 原始管理条目、IOE、身份、指纹、纯匹配、未匹配原因与锚点推进 |
| `statistics-exclusion-store.ts` | 作用域规则、修订号、原子提交；IndexedDB 与内存实现 |
| `statistics-exclusion-candidates.ts` | 预览范围、每级均值 / 中位数、慢局候选和单行均值影响 |
| `player-controller.ts` | 原始与候选快照、规则加载 / 保存、CSV 绑定与发布、多页面协调 |
| `csv.ts` / `csv-session.ts` / `csv-sources.ts` | 原始 31 列、完整读取快照、文件身份、来源版本与关联事务 |
| `ui/exclusion-panel.ts` | 列表定位、范围、分页、选择、预览、排除 / 恢复与焦点管理 |
| `analysis-view.ts` / `view.ts` | 提供已应用范围、统计结果跳转上下文、组件装配 |

`rawVideos` 和原始缓存用于管理；`snapshot.videos`、`dataset.videos` 使用排除后的候选。CSV 先在完整快照中分配负 ID 和 `importOrder`，筛除后保留剩余对象的原始身份及相对顺序。

## 2. 条目身份与 CSV 匹配

网站作用域由数据站点命名空间和玩家 ID 确定，目标使用录像 ID；明细、审核状态和上传时间变化不影响身份。没有明细的缓存行也保留在管理列表中，可按 ID 排除。

CSV 不做数据去重。每个文件的每行都是独立一局，相同内容跨文件不联动；同一文件的相同内容按出现序号区分。

- 真实文件仅用句柄 `isSameEntry()` 判断，文件名只作展示。`sourceId` 保留清单位置，来源 `revision` 区分重新关联前后的文件；新作用域由二者生成，已确认的真实文件或明确沿用关系可恢复历史作用域。
- 指纹保留解引号后的原始 31 列、固定列顺序和字段首尾去空白，并带格式版本；BOM、换行和 CSV 引号写法不改变身份。
- 不使用行号、临时负 ID、导入顺序、时区或显示精度生成持久身份；数值字面值变化可视为内容变化。命中指纹后仍核对规范化原始内容。
- CSV 规则目标包含 `fingerprintVersion / fingerprint / occurrence / canonicalRow`，锚点包含 `recordCount / prefixDigest / sameContentCount`。

| 当前完整快照与已确认依据的关系 | 处理 |
| --- | --- |
| 原序列完整保留为前缀，包括内容不变或仅末尾追加 | 沿用原出现序号；追加的相同内容不继承排除 |
| 原序列变化，但目标在确认时与当前都唯一 | 按内容重新定位 |
| 目标内容不存在 | 保留规则，标为 `missing` |
| 重复目标无法证明原位置关系保留 | 标为 `ambiguous`，不排除任何猜测出的替代条目 |

前缀必须校验规范化序列摘要，不能仅比较文件大小或行数。只有完整读取成功且确实匹配的规则才推进锚点；未匹配、读取失败或取消时保留原依据。记录重新出现且可确认时恢复排除，重复条目仍有歧义时继续未匹配。

例如排除唯一 A 后追加第二条 A，成功刷新须将锚点推进为两条同内容；之后删减为一条 A，应转为歧义未匹配，不能重新按最初的唯一依据确认。

## 3. 文件重新关联与沿用

同一真实文件自动沿用。不同或无法确认身份的文件，原来源存在规则时由用户选择“沿用原排除规则”或“作为新来源”；不根据文件名或相同内容自动沿用。

- 沿用只延续来源关系，新文件仍按上述规则逐条匹配；缺失和歧义目标保持未匹配。
- 明确沿用关系写入 `CsvSourceRecord.exclusionScopeId`，重开和刷新继续生效。一个作用域不能同时作用于两个当前文件，不能重复关联已存在的真实文件。
- 作为新来源不继承原来源规则，原作用域保留。移除关联不删除磁盘文件或排除规则，再选原真实文件仍可恢复规则。
- 无文件句柄 API 时，重新导入不自动继承；用户在面板里明确选择关联历史来源或作为新来源。
- 确认捕获清单修订、来源修订及规则作用域修订。清单与来源始终校验，明确沿用时将 `CsvScopeGuard` 传到提交层。
- IndexedDB 在同一读写事务中读取 `csvSources` 与 `statExclusions`，核对修订和操作有效性后才写绑定；内存实现也在文件读取后预检。失败不留下半完成的来源关系。

## 4. 存储、暂存发布与并发

共享 IndexedDB 为 v5，`statExclusions` 按作用域保存 `owner / rules / revision`，升级保留用户、上传、玩家缓存和 CSV 句柄。重复排除幂等，批量新增、删除、更新规则按期望修订整批提交；冲突后重读，不重放旧操作。

首次加载先读取规则，失败时显示重试，不按空规则发布统计。记录未载入不等于规则未匹配，不据此删除规则。规则不随刷新、重开、版本升级、缓存清理或来源移除自动清理；清除扩展本地数据或卸载后的恢复不在保证范围内。

CSV 发布遵循以下顺序：

1. 从成功读取快照构建局部 `CsvTrial`，计算原始录像、管理条目、未匹配、候选和计数，不改已发布状态。
2. 完成匹配锚点提交。失败或等待期间，订阅、切页、筛选和消息始终使用上一份成功统计。
3. 核对来源流、任务标记、CSV 快照版本、作用域修订和绑定签名；仅放行本次自身提交产生的修订。外部规则变化时重算并重新提交，连续变化超限则保留旧统计等待重试。
4. 校验成功后一次发布快照及其版本，不泄漏中间数据。

锚点写库失败时，内存按规则保留 `{base, advanced}` 待写入依据，后续匹配使用持久规则与这些已确认依据。外部只改同作用域的其他规则时重新基但保留本页依据；原规则被删除、改绑或推进时尊重外部操作，不复活旧目标。

作用域只接纳更高修订；本地提交使旧后台读取失效。跨页面广播仅传作用域与修订，来源关系变化通知重读清单；焦点恢复也核对，晚到结果不能回退状态。

取消、切源、来源移除、快照替换和销毁均使相关异步流程失效。切回网站后，晚到 CSV 事务即使已落库，也只能接纳规则修订供下次使用，不能发布 CSV 录像、错误或版本到网站快照。

`DatasetSnapshot.contentVersion` 只在有效候选数据变化时提升。管理筛选、分页、进度、消息和清除未匹配规则不重建大表；动作携带展示时的 `snapshotKey`，数据更新后清空旧选择并拒绝过期提交。

## 5. 面板范围与展示约定

- 普通列表与慢局候选共用日期、来源、难度、软件 / NF 和 3BV 下限。日期、文件来源在计算基准和截取候选前应用；用时、关键词、分页和前 20 / 50 条只定位列表。
- 每级完整有效集合独立计算局数、总用时和中位数。单行均值影响为 `S/n → (S-t)/(n-1)`，使用未舍入值计算和排序；仅剩一局时显示排除后无有效记录，已排除和范围外记录不重复扣除。
- 已应用时段与统计跳转范围分开保存；日 / 周 / 月入口传实际本地日期交集，周保留三难度，月带入该表难度。默认打开范围完整列表，无数据也不扩大范围。
- 日期处理器独立于用时和关键词处理器。关闭重开保留有效手动、已应用或近30天范围；范围说明区分不限、仅起始、仅结束和完整区间，不隐藏仍生效的限制。
- IOE 使用原始录像的 `bv / (left + right + double)`，保留 3 位小数；字段缺失、非有限或总点击不大于 0 显示“—”，已排除记录仍可显示，未匹配规则显示“—”。不额外抓取明细。
- 打开面板和复制 / 行展开相互独立；关闭恢复入口焦点，入口已被统计重绘删除时回到页面级入口。窄屏在表格内部滚动。
- 今日成绩下方不再显示常驻口径说明；统计与空态不变。
