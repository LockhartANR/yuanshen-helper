# 更新说明

按版本记录面向用户的功能变化。各版本安装包与 SHA-256 校验值见 [GitHub Releases](https://github.com/LockhartANR/yuanshen-helper/releases)。

## 1.3.1 — 2026-11-04

### 新增

- 本地 CSV 支持关联文件，重新打开页面后点击「刷新」即可读取最新成绩，无需重复选择文件
- 新增 CSV 文件管理面板，支持添加、移除和重新关联文件，显示上次读取时间及局数变化；刷新失败或取消时保留上次结果
- 周 T37 表新增逐行复制，包含周日期、局数、ΔT37，以及 T37 / B37 / S37 / PPP 的初中高三级分解，方便分享周成绩

### 调整

- 周、月、年成绩复制中的日期统一使用斜杠，如 `2026/11/04`、`2026/11`

## 1.3.0 — 2026-11-04

### 新增

- 赛博大表新增「梁山分」页签，可查看 LSF 历史走势、变动流水和涨分来源
- 概览与梁山分页新增定阶总览，汇总初中高三级及综合的软实力、NF软实力、LSF、定阶和 NF定阶
- 时段选择增加日、月、年快捷范围及自定义起止日期，全局与梁山分页内的选择同步
- 梁山分增加时段涨分、单局和单日最大涨分统计，点击卡片或图表可定位对应流水

### 调整

- 统一指标名称，仅限制 NF 的指标标注 NF；移除定阶总览底部说明

## 1.2.1 — 2026-11-03

### 新增

- 月均与年汇总表新增逐行复制，可分享周期、局数和平均成绩
- 新增「复制设置」，支持附加指标和实时预览；月均与年汇总分别保存选项，重新打开页面后仍生效

### 调整

- 复制按钮固定在表格右侧，窄屏横向滚动时也可操作

## 1.2.0 — 2026-11-03

- openms.top 玩家页新增「赛博大表」入口，可直接在站内展开分析，也可独立打开
- 设置页新增站内大表入口开关，可控制是否在玩家页显示入口

### 修复

- 修复切到赛博大表后看不到加载进度、失败原因和缺失明细提示的问题

## 1.1.0 — 2026-11-03

- CSV 成绩支持 NF、时段和 3BV 下限筛选，导入时显示文件和行级错误

### 调整

- GC 改为按 3BV 分段统计战力、典型 3BV 和典型用时，并展示三级合计
- 调整 GC 权重与 ASB 统计口径，具体规则见[玩家数据说明](player-stats.md#指标)

## 1.0.1 — 2026-11-02

## 1.0.0 — 2026-11-01

首个正式版：站内用户搜索、录像自动上传、玩家 PB / 前端成绩 / 赛博大表。

### 已知限制

- 部分老录像缺 `path / op / isl` 时，路径、IOE、杂项等指标会跳过该局
- DST 时区下概览仍有少量日期卡按固定 24h 计算；中国时区不受影响
- UI / 玩家接口的自动化测试将在 1.0.1 补齐

### 新增

- 玩家数据页新增「赛博大表」：概览、榜单、趋势、月年、分布、效率、地图七个页签
- 概览：定阶、软实力、LSF（站点锚点、普通 / NF 分开计算）
- 趋势：周 T37 / B37 / S37 / ppp（10/30/99 秒占位补齐）、月均明细、年汇总
- 活跃日历改为 12 周热图 + 右侧统计卡（总对局 / 活跃天数 / 活跃日均 / 最长连续 / 最活跃日）
- PB 表「日期」页签按最早红 / 50% 白 / 最新蓝上色
- 杂项指标改名：最少 / 最多有效点击、最小路径、最少 / 最多岛屿、最少 / 最多开空
- 周 T37 的周行可展开，双列瀑布显示三级槽位明细、总计 / 平均和 T.37 / B.37 / S.37 / BPP / IPP / EPP / PPP37
- 月均明细的月份行可展开，查看「用时分档」「3BVS 分档」占比；rAvg 补原表理论占比
- 概览 GC 增加按 3BV 分档的 asb / 战力贡献明细；年汇总改为三级三卡纵向排列
- 榜单 / 月年 / 效率 / 地图：Top N、月年 Top、oth 七项、热图、效率前沿、狗预测
- 参数面板：Top N、Sub 档数、软实力权重、三级权重、T37 槽位 / 补位 / PPP 常数、3BV 下限、29 档色板阈值、18 项普通 / NF 锚点（大表 / 网站切换）、狗预测目标，保存在本机
- 所有日期统一为 `YY/M/D`（年取后两位，月、日不补零）

### 修复

- 地图狗预测误显示年度达标局数，改为达标概率
- 3BV 下限接入赛博大表所有分析页签，不再只影响 Top5 / LSF
- 缺失 `path / op / isl` 的明细按部分可用缓存，路径 / 杂项等跳过，不再整条丢弃或反复重拉
- 部分明细在「刷新」或缓存过期时会重新拉取，重拉未命中则保留旧部分明细，站点补全字段后可恢复
- 点击字段缺失时 `cl/ce/right` 相关指标不参与统计，月表、年表、月年 Top 显示 `—`
- 「清空本地数据」同时清理玩家录像与明细缓存
- 周 / 日历改为本地日期递推，跨 DST 不再错位
- 明细接口超时会按退避重试；过期网站锚点会提示沿用缓存
- 普通刷新遇到空 `videolist` 时保留已有缓存，手动「刷新」仍以站点为准
- 网站锚点刷新失败时保留已保存锚点，不再被大表锚点永久覆盖
- 「恢复默认」同步重置色板阈值
- 日期色阶偶数个日期取真实中位数，修复两日期时最新日期变白
- `end_time` 为空或非法时回退 `upload_time`
- GC 高级高 3BV 战力系数不再越界归零
- 玩家接口增加 8 秒超时与请求节流队列；未过审补抓与刷新不再互相覆盖

### 变更

- 移除本地判重，重复上传按站点原样计入；同步移除「显示重复」和重复标记
- 赛博大表统一为模式 00、已审核、非比赛录像；3BV 下限默认 10 / 30 / 100，可在参数里改；月 / 年局数仍统计低于下限的全部录像
- 采用工作簿 `Set!AE2:AE30` 的 29 色色板
- 明细缓存升到 v3，旧缓存缺 `path / op / isl` 时重拉

## 0.3.0 — 2026-10-31

### 新增

- 玩家录像数据页：popup 搜索结果行右侧「数据」按钮打开 `player.html?id=<用户ID>`，拉取该用户全部录像在本地重算
- 我的成绩：popup 头部和玩家数据页都加了「我的成绩」按钮，优先用站点登录态直接打开自己的数据页；没登录过 openms.top 时弹窗填一次站内 ID（也可在设置页修改），不额外开标签页
- PB 网格：初 / 中 / 高三个等级同时显示，每行十个 3BV，只画有成绩的 3BV 覆盖到的行；格子可切换显示用时 / 3BVS / STNB，可按软件（avf / evf / mvf / rmv）和 NF 筛选
- 前端成绩（Top5）：初 / 中 / 高三个等级的 time、3BVS、STNB 前五名，普通与纯 NF 分成两张表
- 「含未过审」开关：把 a 未审核 / b 冻结 / d 标识不符 / e 外部审核 的录像也算进来，默认关闭，打开时页面会提示这不是官方口径
- 重复录像识别：同一局被多次导出时按成绩 + 点击结构 + 结束时间判重，默认隐藏，可切换显示；疑似重复单独标记
- 录像明细按用户缓存在 IndexedDB，24 小时内再次打开不重复请求；刷新只补新 ID，打开「含未过审」时才补抓非 `c` 状态的明细
- `npm run verify:player -- <用户ID>` 对拍脚本：用站点接口和本地重算结果逐条比对 PB 与前端成绩

### 变更

- IndexedDB 升到 v3，新增 `playerVideos`、`playerMeta` 两个 store
- 页面上的 PB 与前端成绩都按去重后的集合计算，隐藏重复时不会用同一局占两个名次
- 设置页新增「玩家数据」分组：可手动填写或清除「我的站内 ID」
- 内容脚本每次打开 openms.top 时顺手上报登录态，供「我的成绩」使用；不读 cookie、不开标签页

## 0.2.1 — 2026-10-30

### 改进

- 开始监视前先检查站点登录态，未登录直接弹窗提示并给出登录入口，不再等第一次上传失败
- 上传遇到 401/403 时进入「等待登录」状态，看门狗每分钟探一次，重新登录后自动继续，不用手动点开始
- 工具栏徽标区分状态：等待登录 / 需重新授权显示橙色 `!`，已停止显示红色 `!`，监视中显示待传数量
- 新录像落盘后不再固定等两轮扫描：首次发现时文件已静置超过 3 秒就直接入队，典型延迟从 10–20 秒降到 0–10 秒
- 关闭浏览器或关掉所有窗口即停止监视，下次启动不会自动恢复，需要重新点「开始监视」

## 0.2.0 — 2026-10-30

### 新增

- 录像自动上传：选定本地录像目录后按周期轮询，发现新录像自动上传到 openms.top
- 两种启动方式：「补传已有录像」和「只上传新录像」
- 扫描间隔默认 10 秒，可改 5–300 秒
- 上传台账：重启不重放、不遗漏；支持重试失败、清空台账
- 失败分级：文件级退避重试，账号级（未登录 / 额度满 / 未实名）停止整批
- 目录读取权限失效时提示重新授权
- 诊断面板：后台是否运行、看门狗是否注册、目录文件数 / 子目录数 / 命中数，可在页面里单独扫一次
- 搜索窗口顶部新增「自动上传」入口，权限失效时按钮带橙色提示点

### 变更

- 新增 Service Worker、off-screen 文档和 openms.top 内容脚本
- IndexedDB 升到 v2，新增 `watchHandle`、`watchFiles` 两个 store

## 0.1.0 — 2026-10-26

首个版本。

### 新增

- 数字 ID 精确命中置顶，同时保留文本匹配
