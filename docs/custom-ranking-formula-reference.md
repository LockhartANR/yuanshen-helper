# 自定义排行榜指标公式规则

依据：2026-11-18 工作区中的 `fields.ts`、`filter.ts`、`expression/{tokenizer,parser,validate,evaluate}.ts`。本文描述当前公式实现；分页及排序方式不影响公式值。

## 1. 计算范围

- 每位玩家独立计算每项公式；仅使用当前本地数据集内、具有详情且通过全局筛选的录像。
- 全局筛选先于公式执行。公式不能取回被难度、模式、软件、审核状态、NF、日期或 3BV 下限排除的录像。当前实现要求参与记录的 `bv` 为有限数值。
- 本机统计排除规则不作用于此排行榜。
- 字段表示单局值；聚合函数将同一玩家的多局值转换为一个值。最终指标必须为有限数值或 `null`；`null` 显示为 `—`。
- 原始字段只能位于聚合函数参数内。`max(bvs)` 合法，`bvs` 单独作为指标不合法。
- 可组合多个聚合结果，例如 `sum(bv) / sum(cl)`；禁止聚合嵌套，例如 `avg(max(bvs))`。
- 数值常量公式合法；指标间不能通过名称或 ID 相互引用。

## 2. 字段

字段名区分大小写。未列出的字段不能使用；接口存在的其他字段不会自动成为公式字段。缺失、无效或不适用的值按规范化规则为 `null`，不能默认视为 0。

| 字段 | 类型 | 含义 / 单位 |
| --- | --- | --- |
| `id`、`player` | 数值 | 录像 ID、玩家 ID |
| `software` | 字符串 | 软件代码，例如 `e`、`a`、`m`、`r` |
| `level` | 字符串 | `b` 初级、`i` 中级、`e` 高级 |
| `mode` | 字符串 | 模式代码，标准模式为 `"00"` |
| `state` | 字符串 | 审核状态代码，例如 `"c"` 为已审核 |
| `timems` | 数值 | 原始用时，毫秒 |
| `time` | 数值 | 秒；仅当 `timems > 0` 时为 `timems / 1000`，否则 `null` |
| `bv` | 数值 | 3BV |
| `bvs` | 数值 | `bv / time`，输入缺失时为 `null` |
| `left`、`right`、`double` | 数值 | 左键、右键、双击次数 |
| `left_ce`、`right_ce`、`double_ce` | 数值 | 各类有效点击次数 |
| `cl` | 数值 | 总点击；有限接口值优先，否则取 `left + right + double` |
| `ce` | 数值 | 有效点击；有限接口值优先，否则取 `left_ce + right_ce + double_ce` |
| `clicks`、`effectiveClicks` | 数值 | 兼容别名，分别等于 `cl`、`ce`；新公式使用标准名 |
| `ioe` | 数值 | `bv / cl`；`cl <= 0` 或输入缺失时为 `null` |
| `nf` | 布尔 | `right_ce == 0`；`right_ce` 缺失时为 `null` |
| `path`、`pathCells` | 数值 | 路径原值、路径格数；`pathCells = path / 16` |
| `flag`、`op`、`isl` | 数值 | 插旗、开空、岛屿指标原值 |
| `cell0` 至 `cell8` | 数值 | 接口对应局面指标原值 |
| `file_size` | 数值 | 文件大小，字节 |
| `upload_time`、`end_time` | 字符串 | 上传时间、结束时间原文；不能直接作为时间戳运算 |
| `identifier` | 字符串 | 录像内标识；空字符串规范化为 `null` |

`cl/ce` 的分项派生要求每个分项均为有限数值，否则为 `null`。接口显式 0 有效。计算前会规范化旧快照；旧快照仅有兼容别名值时可作为标准字段的回退来源。

## 3. 字面量与语法

- 数值支持整数、小数及科学记数法，如 `12`、`.5`、`1.2e-3`；不支持十六进制、数字分隔符及无限数值常量。
- 字符串使用单引号或双引号；`\n`、`\t` 分别表示换行和制表，反斜杠后其他字符按该字符本身处理。没有 Unicode 转义解码。
- 布尔和空值关键字为 `true`、`false`、`null`。
- 使用英文括号、逗号和运算符；空白可分隔内容。无注释、变量声明或隐式乘法，`2(time)` 不等于 `2 * time`。

优先级从高到低：

| 顺序 | 运算符 / 结构 | 规则 |
| --- | --- | --- |
| 1 | 括号、函数调用 | 显式分组 |
| 2 | `^` | 乘方，右结合；`2^3^2 = 512` |
| 3 | 一元 `+`、`-`、`!` | `-2^2 = -4`，`2^-2 = 0.25` |
| 4 | `*`、`/`、`%` | 同级左结合；`%` 为余数，`-5 % 2 = -1` |
| 5 | `+`、`-` | 同级左结合，不做字符串拼接 |
| 6 | `==`、`!=`、`<`、`<=`、`>`、`>=` | 同级左结合；区间判断使用 `time >= 10 && time < 20` |
| 7 | `&&` | 逻辑与，短路 |
| 8 | `\|\|` | 逻辑或，短路 |

不支持 `**`、`===`、`?:`、位运算、数组、属性访问或 `Math.*`。

## 4. 条件、比较和空值

- 真值：`true`、非零有限数值、非空字符串为真；`false`、0、空字符串、`null` 为假。
- `!` 返回真值的否定；`&&`、`||` 返回布尔值，不返回操作数。
- 数值与字符串不隐式互转。`"10"` 不是数值 10；确定的混合类型比较或数值运算在校验阶段拒绝。
- 字符串按精确内容比较，区分大小写；大小比较按 JavaScript UTF-16 字符串顺序，不作本地化排序。
- 任一比较操作数为 `null` 时，比较结果为 `null`，包括 `null == null` 和 `null != 0`。检查空值使用 `isNull()`。
- 算术的任一操作数为 `null`，结果为 `null`。除零、余数除零、数学定义域错误和非有限计算结果也为 `null`。
- `if` 仅求值命中的分支；静态校验仍检查两个分支。未命中分支中的未知字段或确定类型错误不会被忽略。

## 5. 聚合函数

令 `N` 为该玩家通过全局筛选的局数；`V` 为逐局表达式 `x` 的有效结果集合。

| 函数 | 参数 | 结果 | 无有效值时 |
| --- | --- | --- | --- |
| `count()` | 无 | `N` | 0 |
| `countValid(x)` | 任意类型表达式 | 非 `null` 结果数；0、false、字符串均计数 | 0 |
| `sum(x)` | 数值或可空数值 | 有效数值之和 | `null` |
| `avg(x)` | 数值或可空数值 | 有效数值之和 / 有效数值个数 | `null` |
| `min(x)` | 数值或可空数值 | 最小有效数值 | `null` |
| `max(x)` | 数值或可空数值 | 最大有效数值 | `null` |

数值聚合忽略逐局表达式的 `null`，不以 0 补位。`sum/avg/min/max` 不接受布尔或字符串；因此 `sum(nf)`、`max(software)` 不合法。

`countValid(time < 10)` 计算“比较结果非空的局数”，不是“小于 10 秒的局数”；false 也会计数。条件计数使用 `sum(if(time < 10, 1, 0))` 或 `countValid(if(time < 10, time, null))`。前者在所有条件均不成立时为 0，后者也为 0。

多个聚合独立筛选各自有效样本。`avg(bv / cl)` 是逐局比值均值；`sum(bv) / sum(cl)` 是两个独立总和之比，样本缺失时两端可能使用不同录像。需要相同样本时对两端使用相同的 `if` 条件。

## 6. 条件与数学函数

`x/y` 均表示数值或可空数值；数学输入为 `null` 时返回 `null`。

| 函数 | 参数数 | 定义 / 限制 |
| --- | --- | --- |
| `if(condition, a, b)` | 3 | 条件为真返回 a，否则 b；数值与 null 分支可组合为可空数值 |
| `isNull(x)` | 1 | x 为 null 返回 true，否则 false |
| `abs(x)` | 1 | 绝对值 |
| `sqrt(x)` | 1 | 平方根；x < 0 时为 null |
| `pow(x, y)` | 2 | 同 `x ^ y`；非实数或非有限结果为 null |
| `log(x)` | 1 | 自然对数；x <= 0 时为 null |
| `exp(x)` | 1 | 自然指数；溢出为 null |
| `floor(x)` | 1 | 向负无穷取整 |
| `ceil(x)` | 1 | 向正无穷取整 |
| `round(x)` | 1 | 按 0 位小数舍入 |
| `round(x, d)` | 2 | d 必须是 0–6 的整数，否则返回 null |

这些函数可以用于逐局表达式或聚合后的运算，例如 `avg(sqrt(time))`、`sqrt(avg(time))`。`min/max` 是单参数聚合函数，不是接受多个标量参数的数学函数。

`round` 当前计算为 `Math.round((x + Number.EPSILON) * 10^d) / 10^d`；负数临界值遵循该实现，不能按绝对值四舍五入推断。所有数值使用 IEEE 754 双精度，存在浮点误差；总和累计溢出时不能得到有效指标。显示精度只影响文本，公式内 `round` 会改变数值。

## 7. 校验与限制

- 最多 2000 个 JavaScript 字符串代码单元、256 个 AST 节点；AST 深度从根 0 计，最大 32。
- 函数名、字段名及关键字区分大小写；参数数量必须匹配上表。
- 数值运算、数学函数、数值聚合和最终结果接受数值或 null，不接受确定的字符串、布尔或混合分支类型。
- `countValid`、`isNull`、逻辑与条件可以读取非数值表达式，但整个指标仍须最终为数值或 null。
- 不支持中位数、百分位、前 N 局聚合、自定义函数、指标引用、日期函数、正则或网络访问。
- 不执行 JavaScript、赋值、循环、动态导入、DOM 或存储操作。

页面样本提示不表示录像交集：`count()` 为 N；`sum/avg/min/max` 为各自有效数值数；当前 `countValid(x)` 的提示为 N，其指标值才是有效数。常量的提示为 N；一元运算及 `isNull` 沿用输入；二元运算取两端提示较小值，短路时沿用左端；数学函数取参数提示较小值；`if` 只取所选分支的提示。

## 8. 公式示例

| 目标 | 公式 |
| --- | --- |
| 局数 | `count()` |
| 初级最快用时，秒 | `min(if(level == "b", time, null))` |
| 中级最快用时，秒 | `min(if(level == "i", time, null))` |
| 高级最快用时，秒 | `min(if(level == "e", time, null))` |
| 高级平均用时 | `avg(if(level == "e", time, null))` |
| 最高 3BVS | `max(bvs)` |
| 平均 IOE | `avg(ioe)` |
| 总 3BV | `sum(bv)` |
| NF 局数 | `sum(if(nf, 1, 0))` |
| 高级且少于 60 秒的局数 | `sum(if(level == "e" && time < 60, 1, 0))` |
| 用时有效时的 Sub60 比例 | `avg(if(isNull(time), null, if(time < 60, 1, 0)))` |
| 三难度最快用时之和 | `min(if(level == "b", time, null)) + min(if(level == "i", time, null)) + min(if(level == "e", time, null))` |
| 比较值保留三位 | `round(max(bvs), 3)` |

三级分别统计时，全局难度须勾选对应级别。三难度用时之和缺任一级时为 null；不自动用 0 或补位值代替。`if(nf, 1, 0)` 将未知 NF 也计为 0；需要排除未知样本时先检查 `isNull(nf)`。
