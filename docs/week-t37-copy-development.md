# 周 T37 数据复制 — 开发文档

状态：待开发。日期：2026-11-04。以当前工作区的趋势页和年月复制实现为基线。

## 1. 目标与范围

在「赛博大表 → 趋势 → 周 T37」补齐逐周复制，与已有月均、年汇总保持相同的操作方式：每行提供「复制」，卡片顶部提供「复制设置」，支持预览、可选内容和本机保存。

已确认的内容：

- 默认复制周日期范围、局数、T37、B37、S37、PPP、ΔT37。
- 三级 PP 和槽位明细作为可选内容，默认关闭。
- 复制使用当前页面的统计结果，不另算一套周统计。

本文补充的默认约定包括三行基础文本、数值精度、选项分组、预览目标和筛选说明，供开发与验收使用。本轮增加周复制，不调整 T37、PP、PPP 算法和现有年月复制文本。

## 2. 默认复制文本

每个有成绩的周可复制一段纯文本，默认三行，同一行的字段使用 ` | ` 分隔：

```text
周成绩 · 2026-10-26–2026-11-01
Games 128 | T37 820.1 | ΔT37 −12.3
B37 42.1 | S37 1532.4 | PPP 2.345
```

以上数值用于展示格式。格式规则如下：

| 字段 | 格式与含义 |
| --- | --- |
| 周日期 | 本地时区的周一至周日，完整 `YYYY-MM-DD–YYYY-MM-DD`，包含两端日期 |
| Games | 当前周统计的局数，整数，不加千位分隔符，与已有年月复制保持一致 |
| T37 / B37 / S37 | 各保留 1 位小数，与周表主行一致 |
| PPP | 保留 3 位小数，与周表主行一致 |
| ΔT37 | 保留 1 位小数；正值带 `+`，负值使用 `−`，无比较对象显示 `—` |

零差值输出 `+0.0`；小于显示精度的差值归零后也输出 `+0.0`，避免 `−0.0`。周表主行与复制共用差值格式化，必要时同步修正主行的负零显示，不改变差值计算。真实的 PPP 或其他指标为 0 时按对应精度输出，不能替换为 `—`。

日期用日历运算从周一起点得到周日，不通过固定毫秒数推算，不使用 UTC 日期截断，覆盖跨月、跨年和夏令时场景。当前周仍以完整自然周作为周期标签。

### 2.1 筛选说明

标题仅在实际限制软件或 NF 时追加范围标记，例如：

```text
周成绩 · 2026-10-26–2026-11-01 · avf · 仅 NF
```

未限制时不增加「全部」「普通」等字样，也不把周综合结果标成某一个难度。

若全局时段截取了自然周的一部分，固定三行后追加一行说明实际筛选日期，例如：

```text
统计日期 · 2026-10-28–2026-10-30
```

此日期取该周与已应用全局时段的交集，而非该周最早、最晚录像日期。未截断自然周时不输出。说明不改变周统计、不作为可选项；预览与复制使用同一份筛选上下文。

## 3. 可选复制内容

周卡片的「复制设置」提供两个独立复选项，勾选后自动保存：

| 选项 | 设置标识建议 | 输出 |
| --- | --- | --- |
| 三级 PP | `levelPp` | 初级、中级、高级 PP 合并为一行 |
| 槽位明细 | `slots` | 按初级、中级、高级顺序追加槽位表、总计和平均 |

全部开启时，输出顺序固定为：基础三行 → 必要的统计日期说明 → 三级 PP → 初级明细 → 中级明细 → 高级明细。勾选顺序不影响文本顺序。

### 3.1 三级 PP

输出格式：

```text
BPP20 1.23 | IPP12 2.34 | EPP5 3.45
```

该例仅展示格式，三个值均取被复制周的实际结果，保留 2 位小数。

`20 / 12 / 5` 后缀必须来自该周各级 `slot`；用户修改槽位参数后同步变化，不能硬编码默认数量。某一级没有成绩时，按现有计算结果输出 0。

### 3.2 槽位明细

每级按以下结构输出，示例为省略展示，实际复制不能用省略号代替任何槽位：

```text
初级 · 20 槽
排名 | T | B | S
1 | 1.234 | 8.123 | 100.12
……
总计 | 40.000 | 100.000 | 2000.00
平均 | 2.000 | 5.000 | 100.00
```

- T 保留 3 位、B 保留 3 位、S 保留 2 位小数，与现有展开明细一致；总计和平均使用相同精度。
- 槽位数量、补位用时、0 值、总计和平均直接复用 `WeekLevelDetail`，不重新从录像挑选。
- 同一行是三张独立榜的相同排名，不能解释为同一局录像，也不附加录像 ID 或录像日期。
- 不根据“数值等于补位值”推断是否为补位；本轮不新增逐格补位标记。
- 「槽位明细」与「三级 PP」独立：只选槽位明细时，不额外输出 PP 行。
- 不要求先展开周行才能复制。复制全部实际槽位，不受页面折叠或滚动位置影响。

## 4. 页面交互

### 4.1 行内复制

- 周表最右侧增加复制列，每个有成绩的周一枚真实 `button`，支持鼠标、Enter 和 Space。
- 可访问名称含周日期，例如「复制 2026-10-26 至 2026-11-01 周成绩」。
- 点击复制不展开或收起周明细，不改变当前筛选、页签和滚动位置。
- 沿用现有「复制 → 已复制 / 复制失败 → 复制」反馈与剪贴板降级方式。
- 增列后同步调整周明细行和空态行的 `colspan`，默认由 7 改为 8。
- 使用现有表格滚动容器和右侧吸附复制列样式；窄屏允许表格内部横向滚动，页面本身不横向溢出。

### 4.2 设置与预览

- 周卡片顶部增加「复制设置」，使用已有复制面板的视觉样式，独立控制展开状态。
- 面板固定内容提示为「周日期与局数、T37 / B37 / S37 / PPP / ΔT37（始终保留）」。
- 预览默认取当前可见列表中时间最新的有成绩周。当前周列表按时间升序，不可误用数组第一项作为最新周。
- 预览标题明确指出对应周；没有有成绩周时显示「暂无数据可预览」，仍允许设置选项。
- 勾选、恢复默认后即时更新预览，并保留面板展开状态和当前键盘焦点，不为此重建整张趋势页。
- 切换数据源、时段、软件、NF 或统计参数后，预览跟随本次新统计结果，不显示旧周内容。

### 4.3 保存与恢复默认

- 新增 `weekCopyFields`，默认空数组，沿用现有 `analysisSettings` 存储，不另建一套 localStorage 配置。
- 周、月、年的复制选项独立保存；周 PP 与槽位明细包含三级内容，不按难度分别存选项。
- 旧设置没有该字段时按空数组处理；非法字段剔除，重复值去重，并归一化到固定顺序。
- 周面板「恢复默认」只清空周复制可选项；顶部参数「恢复默认」同时还原周、月、年的复制配置及其他参数。
- 展开状态只属于当前视图会话，不持久化。

## 5. 数据口径与边界

| 项目 | 规则 |
| --- | --- |
| 数据来源 | 网站、独立 CSV、普通玩家页 CSV 和站内嵌入的大表沿用各自现有结果，不新增网络请求 |
| 周列表 | 沿用现有最近 10 周、有成绩周展示逻辑；不为复制额外扩展查询范围 |
| 全局筛选 | 复制使用与周表相同的软件、NF、时段、3BV 下限和统计参数 |
| 难度切换 | 月均难度切换不影响周综合结果和周复制，不借用 `trendLevel` 给周复制贴单级标签 |
| ΔT37 | 当前周 T37 减去当前已显示列表中上一条有成绩周的 T37；可能跨过空周，不改成相对上一个自然周 |
| 无前项 | 当前列表第一条的 Δ 为 `—`；不向列表外寻找比较对象，不拿空周补位结果作差 |
| 空周 | 沿用隐藏规则；无数据时没有可点击的周复制按钮，不复制一份纯补位成绩 |
| 缺少某级 | 有周成绩但某级没有成绩时，保留该级真实的补位、0 和 PP 计算结果 |
| 跨日 | 日期范围和周起点来自同一轮渲染的统计上下文，不在复制点击时单独获取另一份“现在” |

数值先用未舍入值完成差值和统计，再按输出精度格式化。复制与预览必须来自同一纯函数，不能从 DOM 的已格式化文本逆向拼接，也不能在点击时再次聚合录像。

| `src/styles/player.css` | 优先复用复制列与设置面板样式，只补必要的周表布局差异 |

实现时特别检查以下现有分支：

1. 复制类型显式区分 `today / week / month / year`。周没有单级 `level`，先处理周分支，不能在统一入口处因缺少 `level` 提前拒绝。
2. 建议统一使用 `data-copy-kind` 选择复制按钮；同步给今日按钮补上 `today` 标识，保留已有今日复制功能。不要为周伪造某个难度。
3. 未知类型直接拒绝，不能把所有非月类型默认当成年汇总；设置、重置和复选框事件同样显式区分三种周期。
4. 复制按钮在周行展开事件之前处理，处理完立即返回。异步复制完成后，仅反馈仍连接在文档中的原按钮，不操作重绘前的旧节点。
5. 用周起始时间等稳定标识查询本轮周快照，不使用显示行号；切筛选后目标不在快照中时不复制旧内容。
6. 保存周快照时同时确定其比较对象与 Δ，保证主行、复制、预览共享同一口径。用时变化说明相对上一条有数据周，不重新查历史。

可以将周期配置提取为小型映射，复用现有复制面板，避免继续叠加“不是月就是年”的分支；不为三个周期引入新的通用框架或第二套剪贴板工具。

真实浏览器验收：

1. 周行点击复制后读取实际剪贴板，核对三行文本、Δ 与主行一致，周明细展开状态不变。
2. 分别启用 PP、槽位明细、全部启用，对照展开明细检查；不展开周行也能复制完整内容。
3. 修改槽位参数后检查 PP 后缀、槽位数量、总计和平均；刷新页面确认选项保存。
4. 切换月均难度、NF、软件和自定义日期，核对周复制、最新周预览和筛选说明。
5. 网站与本地 CSV 至少各验收一次，CSV 刷新后不再复制旧结果；站内嵌入页验证同一套入口可用。
6. 窄屏检查右侧按钮、表格内部滚动和展开行宽度；验证 Enter / Space、复制失败反馈。
7. 回归今日、月均和年汇总复制及恢复默认。

交付前运行 `npm run verify`、`git diff --check`。如真实剪贴板或嵌入页未实际验收，应明确记录未执行项，不用模拟剪贴板测试替代真实浏览器结论。
