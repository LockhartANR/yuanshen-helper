# 元神助手

> 本项目不是 openms.top 官方项目。

## 简介

为 [开源扫雷网（openms.top）](https://openms.top) 提供辅助功能的 Chrome 扩展。

当前版本 **0.2.2**。提供站内用户搜索（用户名、实名、英文名、拼音、数字 ID、扫雷标识）和录像自动上传（监视本地录像目录，按周期把新录像传到站点）。所有数据只保存在本机，不上传任何服务器。

## 功能

- **本地用户搜索**：用户名、实名、英文名、拼音全拼、拼音首字母、数字 ID
- **智能排序**：完全匹配、前缀匹配、包含匹配分级排序；纯数字优先按 ID 精确命中
- **多词英文名**：`San Zhang`、`Zhang San`、`SanZhang` 都可匹配
- **标识反查**：搜索框右侧「标」开关，默认关闭；开启后按需查询扫雷标识
- **未绑定标识标记**：未关联站内账号的标识单独分组，带「标识 / 未绑定」标记
- **同步管理**：全量 / 增量同步、取消、断点续跑、清空本地数据
- **键盘操作**：`↑` / `↓` 选择，`Enter` 打开，`Esc` 关闭
- **姓名状态**：区分普通实名、匿名、隐藏实名
- **录像自动上传**：选定本地录像目录后按周期轮询，新录像自动传到站点；支持「补传已有」和「只传新的」
- 浅色 / 深色主题跟随系统

## 安装

### 方式一：Release 包

1. 从 [Releases](../../releases/latest) 下载 zip 并解压到固定目录
2. 按下方「加载扩展」操作

Release 包只包含构建后的扩展文件，不包含源码或 Node 依赖。

### 方式二：从源码构建

环境要求：

- Chrome 120+
- Node.js 20.19+ 或 22.12+（仅构建需要）

```bash
npm ci
npm run build
```

### 加载扩展

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的扩展目录（从源码构建则选择 `dist/`）
4. 将「元神助手」固定到工具栏

## 使用方法

### 首次同步

1. 点击扩展图标打开搜索窗口
2. 点击右下角「同步」或空状态里的「立即同步」
3. 同步完成后输入名字片段开始搜索

同步只请求用户的 ID 列表和批量资料，不会拉取录像、排行榜或标识数据。

### 搜索

- 输入中文实名、用户名、英文名、拼音、首字母或数字 ID
- 点击结果在新标签页打开 `https://openms.top/#/player/{id}`
- `↑` / `↓` 切换结果，`Enter` 打开，`Esc` 关闭
- 输入纯数字时，ID 精确命中排在最前，同时继续匹配文本

### 标识反查

标识是扫雷软件（元扫雷 / Minesweeper Arbiter）写进录像文件的账号串。

- 默认关闭；点击搜索框右侧「标」按钮开启
- 输入至少 3 个字符，停止输入 400 ms 或按 Enter 后查询
- 只有本地结果少于 5 条时才会触发远程查询
- `icontains` 最多 5 次/分钟，结果缓存 1 小时
- 命中本地用户时显示「标识」标签；未绑定标识在「标识结果」分组中单独展示
- 关闭开关后不会发起标识请求，也不会显示标识结果

### 设置页

点击搜索窗口右上角齿轮，或右键扩展图标选择「选项」：

- 查看本地用户数、上次同步时间、当前水位
- 全量 / 增量同步、取消、清空本地数据
- 修改 API 根地址（默认 `https://openms.top`）
- 开关「打开 popup 时自动增量」
- 查看最近 20 条日志

### 自动上传

搜索窗口右上角的「自动上传」图标（第二个按钮），或设置页右上角「自动上传 ↗」，都能打开这个页面：

- 顶部还有一个 ▶ / ⏸ 快捷按钮：不打开页面也能直接开始 / 暂停监视
- 如果缺目录、没授权或没登录，点 ▶ 会自动跳转到这个页面，并直接给出对应提示
- 页面右上角有「控制台 ↗」，可以回到用户搜索和同步的设置页

1. 点「选择目录」，选中扫雷软件保存录像的文件夹（浏览器会询问一次读取权限）
2. 选择启动方式：
   - **只上传新录像**：目录里已有的录像不传，只传启动之后出现的
   - **补传已有录像**：先把目录里已有的全部传一遍，再继续监视
3. 扫描间隔默认 10 秒，可改 5–300 秒
4. 点「开始监视」

运行说明：

- 录像落盘后最多等一个扫描周期就会被发现；文件如果已经静置超过 3 秒，当轮直接入队
- 刚写完（3 秒内）的文件会多等一轮，确认大小没再变才上传，避免把正在写入的录像传上去
- 上传走 openms.top 页面里的同源请求，复用浏览器里已有的登录状态，不需要重新登录
- 开始监视前会先检查站点登录态；未登录会直接提示，并在页面上给出登录入口
- 上传途中登录失效会进入「等待登录」，每分钟探一次，重新登录后自动继续
- 判定「网站已有」（`collision`）视为成功；未完成局跳过；其余失败按原因记录，网络类自动退避重试
- 额度满、未实名会停止整批并说明原因，不会反复重试
- 关掉设置页不影响；关闭浏览器或关掉所有窗口即停止监视，下次启动需要重新点「开始监视」（并重新授权一次目录）

## 搜索规则

匹配前会做归一化：去首尾空格、转小写、全角转半角、合并连续空格。

搜索字段：

- `username`：站内主称呼
- `realname`：实名；匿名时为空，隐藏实名时整组排除
- `firstname` / `lastname`：英文转写
- 组合英文名：正序、倒序、无空格形式
- 拼音全拼 / 首字母
- 数字 ID

匹配方式按优先级：

1. 完全相等
2. 前缀匹配
3. 包含匹配

排序时依次比较：来源（ID > 文本 > 拼音 > 标识）、匹配类型、字段优先级、显示名长度、ID。不做编辑距离纠错、分词、同义词、繁简转换，也不按排名或录像数排序。

## 隐私与安全

- 用户资料只保存在本机浏览器的 IndexedDB 中，不上传、不埋点、不接第三方统计
- 默认只访问 openms.top 的公开只读接口，遵守站点限流；修改 API 根地址后只应使用可信地址
- 只存搜索必需字段：ID、用户名、实名、英文名和派生搜索字段；不存国家、签名、头像、封禁标记
- 隐藏实名的三个姓名字段不进入索引；匿名用户的 `匿名` 不作为姓名索引
- 标识查询结果会在本机缓存 1 小时；限流时间戳也只存本机
- 自动上传只读取你选中的目录，只上传录像文件本身；目录句柄和上传台账只存在本机
- 设置页提供「清空本地数据」
- 本扩展会在本机保存站内用户的实名信息，请勿在共享电脑上使用，也不要导出或公开分享这些数据
- 请遵守 openms.top 的使用规则；如果站点维护者要求停止使用，请停止使用并清空本地数据

## 开发

```bash
npm ci
npm run typecheck   # TypeScript 类型检查
npm test            # 55 个单元 / 集成测试
npm run build       # 产物输出到 dist/
npm run watch       # 持续构建；改完在 chrome://extensions 重新加载
```

**不要用 `vite dev` 加载扩展**：MV3 的 CSP 禁止 Vite dev 注入的 inline script / HMR，会导致页面空白。开发时使用 `npm run build` 或 `npm run watch`，然后在 Chrome 里重新加载扩展。

`public/manifest.json` 中的 localhost host permission 仅用于本地后端调试；发布前可按需移除。

### 站点数据

用户资料和标识查询使用 openms.top 提供的公开只读接口。这些接口属于第三方站点，不是本项目提供的服务，可能变更或限流；扩展只按公开接口访问，并遵守站点限制。接口封装见 `src/features/user-search/api.ts`，具体以站点公开文档为准。

自动上传的架构、调度方式和实现过程中的坑记录在 [`docs/upload-watch-plan.md`](docs/upload-watch-plan.md)。

## 限制

- 删除账号只会在全量同步时从本地清理；增量接口没有墓碑
- 隐藏实名用户无法按实名搜索，这是站点设计
- 拼音多音字可能选错读音，文本搜索仍可兜底
- 标识反查依赖网络和站点限流；同一查询缓存 1 小时
- 自动上传只在浏览器打开时工作；关闭浏览器期间不会上传，重启后也不会自动恢复
- 自动上传不会输入绝对路径，只能通过目录选择器选择文件夹；浏览器重启后需要重新授权一次
- 自动上传需要一个 openms.top 标签页承载同源请求，没有时会自动在后台打开一个
- 用户搜索数据仍不会后台自动更新，只有自动上传有 Service Worker
- 未上架 Chrome Web Store，只支持手动加载已解压目录（Release 包或 `dist/`）
